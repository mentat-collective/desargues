# Showcase

Every picture on this page, and in the README gallery, is generated by
[`dev/desargues/showcase.clj`](../dev/desargues/showcase.clj). Each picture
comes from one entry of its `entries` vector. The constructs are the ones the
JavaFX stage and the browser page play. They are recorded through the pure
`RecordingBackend`, played by the player (`desargues.player.graph-source`) and
painted by the headless PNG host (`desargues.player.headless`). No JavaFX,
Manim or browser is involved; the GIFs go through ffmpeg.

```bash
clojure -M:showcase                       # or: bb showcase  (everything, about 3 min)
clojure -M:showcase --only plot,kepler    # some entries
clojure -M:showcase --list                # ids, durations, namespaces
```

The `browser-*.png` screenshots at the end come from
[`browser/screenshots.mjs`](../browser/screenshots.mjs) (Playwright, see below).

## Adding a picture

An entry is plain data. A new demo, such as the partial-derivatives 3D demo
that is in progress on another branch, needs one more map in `entries` (the namespace and var names below are
placeholders):

```clojure
{:id     :partials                       ; -> doc/showcase/partials.png (+ .gif)
 :title  "partial derivatives"
 :ns     "desargues.player.calculus-demos"
 :caption "a surface z = f(x, y) with its partial slices at a point"
 :source  calculus-demos/source-fn       ; (fn [params] ISource)
 :params  calculus-demos/defaults
 :t       :end                           ; the instant the still shows
 :camera  {:yaw -0.6 :pitch 0.7}         ; 3D sources only: merged over theirs
 :gif     {:fps 15 :seconds 4 :size [560 315]
           :at (fn [u] {:t :end :camera {:yaw (* 2 Math/PI u)}})}}
```

`:source` is any `(fn [params] ISource)`. For a parametric construct
`(fn [params] (fn [stage] ...))`, wrap it with `(construct-source construct)`.
For a logic flow, use `(logic-source #(flow/record ...))`, which also typesets
the flow's TeX labels. A GIF samples `:at` for u from 0 to 1, or t from `:from`
to `:to`. `:at` can change the time, the params (each distinct params value is
recorded once) or the camera.

## Logic flows, `desargues.logic.scene.*`

Each flow is plain beat data played through `desargues.logic.scene.beats/play!`.
Its `record` function returns the scene graph. The site build typesets the TeX
labels with latex and dvisvgm; here `logic-source` hands them to JLaTeXMath.

```clojure
{:id :venn :source (logic-source #(venn/record "venn" '(= (diff A B) (diff B A)))) :t :end}
{:id :truth-table
 :source (logic-source #(table/record "table" '(iff (not (or P Q)) (and (not P) (not Q))))) :t :end}
{:id :proof
 :source (logic-source #(proof/record "proof" transitivity-proof :library proof-library)) :t :end}
{:id :refute
 :source (logic-source #(refute/record "refute" '(iff (implies P Q) (implies (not Q) (not P))))) :t :end}
{:id :hasse :source (logic-source #(hasse/record "hasse" divisors-of-12 {:subset #{4 6}})) :t :end}
```

| | |
|---|---|
| ![Venn](showcase/venn.png) A − B = B − A fails: the differing regions turn red | ![truth table](showcase/truth-table.png) De Morgan's law, a tautology |
| ![proof](showcase/proof.png) transitivity of ⊆ by element chasing, checked | ![refutation](showcase/refute.png) contraposition: every branch clashes |
| ![Hasse](showcase/hasse.png) divisors of 12: covers, join and meet tables | |

## In the browser

`browser/screenshots.mjs` serves `browser/public` and opens a few demo pages in
headless Chromium. It sets their widgets the way a user would, then captures
the stage and the widget panel.

cd browser && npm i --no-save --no-package-lock --ignore-scripts playwright

## Calculus objects (`desargues.objects.calc.*`)

Integrals, tangents and solids are data. A constructor of
`desargues.objects.calc.core` builds each object (`area-under`, `riemann`,
`area-between`, `tangent-line`, `secant`, `secant->tangent`, `accumulation`,
`revolution` (:disk :washer :shell), `double-integral`, `vector-field`,
`line-integral`). A figure layers objects over a `plane` or `space` view, and
its slots may hold param refs `(p :n)`, so widgets or the clock move them.
Each target is a single multimethod: `problems`, `value` (computed through the
numeric port: `:jvm`, or `:raster` when it is loaded), `->shapes` (player
frames) and `->emmy-viewers` (Mafs/MathBox/Leva, in `notebooks/`). The
readout prints the numeric value beside Emmy's exact one (16/3, 14/3 π).

```bash
clojure -M:showcase --only calc-area,calc-riemann,calc-between,calc-tangent,calc-ftc,calc-work,calc-solid,calc-solid-shell,calc-columns
clojure -M:notebooks -m desargues.calc-emmy-check   # builds notebooks/calculus_objects.clj
```
